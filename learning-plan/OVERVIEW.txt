📚 6-PHASE LEARNING ROADMAP
═════════════════════════════════════════════════════════════════════════════════

PHASE 1: HIGH-LEVEL ARCHITECTURE (30-45 min)
───────────────────────────────────────────────────────────────────────────────
Goal: Build mental models of the system
Topics:
  • Project structure & organization
  • Tech stack (Bun, React, Ink, Anthropic SDK)
  • 8 core architecture diagrams
  • Request lifecycle overview (input → output)
Key Files: README.md, AGENTS.md, docs/reference/project-structure.md
Checkpoint: Can you draw the system architecture?


PHASE 2: CORE ENGINE & PIPELINE (2-3 hours)
───────────────────────────────────────────────────────────────────────────────
Goal: Understand how requests execute
Topics:
  • QueryEngine deep dive (main orchestrator)
  • Tool system architecture (definition → execution)
  • Message & context flow
  • Anthropic SDK integration
Key Files: src/QueryEngine.ts, src/Tool.ts, src/tools/, src/context.ts
Checkpoint: Can you trace a query from input → tool → result?


PHASE 3: UI & TERMINAL RENDERING (1.5-2 hours)
───────────────────────────────────────────────────────────────────────────────
Goal: Learn how React + Ink creates interactive terminal UI
Topics:
  • Ink terminal rendering engine
  • TUI components & layouts
  • Terminal input & output handling
Key Files: src/ink/, src/components/, src/screens/REPL.tsx
Checkpoint: Can you create a simple Ink component?


PHASE 4: MULTI-AGENT SYSTEM (2-3 hours)
───────────────────────────────────────────────────────────────────────────────
Goal: Master the sophisticated agent orchestration
Topics:
  • AgentTool routing (4 agent types)
  • Agent execution engine (lifecycle & query loop)
  • Context forking & caching
  • Team coordination & swarm infrastructure
Key Files: src/tools/AgentTool/, src/utils/forkedAgent.ts, src/utils/swarm/
Checkpoint: Can you spawn an agent and trace its execution?


PHASE 5: ADVANCED FEATURES (1-1.5 hours)
───────────────────────────────────────────────────────────────────────────────
Goal: Explore sophisticated add-ons
Topics:
  • Memory system (cross-session persistence)
  • Skills system (extensible workflows)
  • Channel system (Telegram/Feishu remote control)
  • Computer Use (desktop automation)
  • Desktop app (Tauri + React GUI)
Key Files: docs/memory/, docs/skills/, docs/channel/, desktop/
Checkpoint: Can you explain one advanced feature?


PHASE 6: HANDS-ON DEVELOPMENT (3-5 hours)
───────────────────────────────────────────────────────────────────────────────
Goal: Build custom extensions to cement understanding
Topics:
  • Building custom tools
  • Adding slash commands
  • Creating skills & workflows
  • Extending with third-party models
Key Files: src/tools/, src/commands/, src/skills/
Checkpoint: Can you build and test a custom tool?

🎯 LEARNING APPROACH
═════════════════════════════════════════════════════════════════════════════════

For each topic:
  1. READ (20-30 mins)     — Primary source files & documentation
  2. TRACE (15-20 mins)    — Add console.log, run locally, observe flow
  3. MODIFY (10-15 mins)   — Change something small, verify behavior
  4. BUILD (20-45 mins)    — Create tool, component, or command
  5. DEBUG (15-30 mins)    — Fix issues, learn from errors
